# Velvet 1.0.0

An independent Windows desktop music player with a customisable interface, local-library playback, playlists, a persistent queue and real audio controls.

- Three original Velvet Sessions demo compositions to try immediately.
- Local file/folder imports with a duplicate and availability preview.
- Tone controls, parametric/graphic EQ, ambience, dynamics and stereo processing for local audio.
- Theme and layout preferences with export/import, plus uploaded photo, GIF and looping video backgrounds with blur and dimming.
- Curated song suggestions, MusicBrainz recording metadata search and official provider search links.
- Playlist exchange in Velvet JSON, CSV and M3U/M3U8.

Spotify, YouTube Music and SoundCloud links are references opened in the original service. Account-connected streaming, downloads, service sync, lyrics, crossfade and executable third-party plugins are not included. See the source feature matrix for the full scope.

Download the Windows x64 ZIP, extract every file, and open Velvet.exe. Compare the ZIP with SHA256SUMS.txt. This preview build is unsigned and has no automatic updater. Your imported music stays in its existing folder; app preferences and library records are stored locally.


The Windows build passed all 16 native desktop checks, actual offline audio rendering, unit checks and backend persistence checks. The live song-catalogue query succeeded. See docs/VALIDATION.md for the exact scope and remaining limits.
