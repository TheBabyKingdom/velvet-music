# Velvet 1.1.0

Search for songs and listen directly inside Velvet.

- Live Audius song search returns available full-length public tracks.
- Play, pause, seek, volume and the audio suite work in the existing Velvet player.
- Add streaming songs to favourites, mixed-source playlists and a persistent queue.
- Discover public trending songs with artwork.
- Existing image, GIF and video backgrounds, themes and local-file features remain available.
- Pressing Play never opens a different website or app.

The catalogue is provided by Audius; availability varies, and other services' complete catalogues are not included. Restricted, gated and private recordings are excluded. Saved references from other services find possible playable versions in the app and require your choice before playing a different recording.

Extract the full Windows ZIP and open Velvet.exe. The application is unsigned; checksums are included.
